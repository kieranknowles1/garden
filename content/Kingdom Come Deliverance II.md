# Alchemy for the Impatient/Multitasker
## Artemisia -- Strength, Reduced Stamina Usage.
1. Spirits
2. Add 2x wormwood to mortar
3. Add 1x sage to pot
4. Start boil
5. Grind and add wormwood
6. Boil 1 $1\over2$ turns
7. Distill
## Marigold Decoction -- Healing
1. Water
2. Add 1x nettle to pot
3. Start boil
4. Grind and add 2x marigold
5. Pour
## Moonshine -- All Henry Needs
1. Spirits
2. Add 2x wormwood to pot
3. Start boil
4. Grind and add 2x mint
5. Boil $1\over2$ turn
6. Raise pot and distill
## Nighthawk -- Night Vision
For a weaker, shorter lasting effect:
1. Water
2. Add 2x eyebright, 1x belladonna, 1x camomile to pot
3. Pour
